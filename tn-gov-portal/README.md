# TN Government Services Portal

React + Tailwind CSS + LocalStorage. No backend.

## Run
```
npm install
npm run dev
```

## Merge into an existing project
Copy `src/App.jsx`, `src/utils.js` and `src/components/` into your `src/`. Make sure Tailwind CSS is set up (`@tailwind` directives in your CSS).

LocalStorage keys: government_categories, government_departments, government_services, government_issues.
